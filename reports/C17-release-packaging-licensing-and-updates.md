# C17: Release packaging, licensing and updates

Researched 2026-10-30. Brief file unavailable; scope taken from the task line. Prices read 2026-10-30. Native AOT measurements are Linux x64 only (no Windows machine here).

## Answer

Package Studio with **Velopack**. It gives a per-user `Setup.exe` for individual users. Its `--msi` option builds an MSI for IT teams, which supports per-machine installs, silent `msiexec` and Group Policy. Velopack is MIT-licensed, ships binary delta updates, and can sign through signtool or Azure Artifact Signing. Its NuGet package (1.2.161) compiled under Native AOT with zero trim or AOT warnings in our Linux test, adding 3.7 MB over a plain HttpClient app. Also publish a WinGet manifest. Sign with an **OV certificate whose key is held in a cloud HSM** (hardware security module) or on a token. Examples: GlobalSign USD 289 a year with your own HSM, or USD 529 (AED 1,945) with a USB token; Certum cloud EUR 209; SSL.com USD 129 a year plus key storage. Microsoft's Artifact Signing costs only USD 9.99 a month, but it accepts organisations in the USA, Canada, the EU and the UK only. EV certificates no longer skip SmartScreen warnings, so they are not worth the premium. From 1 March 2026 every new certificate lasts at most 460 days (CA/Browser Forum ballot CSC-31). For module licensing, use **Keygen** or **Cryptlex**. Keygen Std 1 costs USD 99 a month for 1,000 active users and covers entitlements, floating seats, signed offline licence files and a free self-hosted edition. Cryptlex Starter costs USD 100 a month and does offline activation with request and response files; its LexActivator wrapper compiled cleanly under AOT. Avoid the LicenseSpring .NET SDK if Native AOT is required: our build showed 170 AOT/trim warnings and crashed at start. For crash reports, use Sentry's .NET SDK 6.12.1 behind an explicit opt-in. It was AOT-clean and statically links sentry-native for native crashes. Run it on Sentry SaaS (Team USD 26 a month billed annually), or self-host Sentry or GlitchTip if GCC clients need the data kept in their region. Sell Studio as an annual named-user subscription with paid modules. Benchmarks: Giraffe Teams USD 1,500 per user per year, Modelur EUR 888 per floating seat per year, TestFit Parking Solver USD 195 a month, Rhino 9 USD 995 perpetual. Offer floating and offline-activated seats for government buyers. Main caveats: all AOT results are Linux-only, and Windows AOT, MSI building and signing were not tested. Autodesk Forma prices could not be read because Autodesk's pages blocked automated access.

## Detail

### MSIX versus WiX or Inno

**MSIX** is the strongest format technically. It downloads only changed 64 KB blocks, uninstalls cleanly, and Intune and Configuration Manager can deploy it [[8]](https://learn.microsoft.com/en-us/windows/msix/overview). Updates outside the Store go through an `.appinstaller` file. That file can check on launch, every N hours (0 to 255, default 24), or in the background every 8 hours [[10]](https://learn.microsoft.com/en-us/windows/msix/app-installer/update-settings). Two issues make it a poor first choice for Studio:

1. **One-click web install is gone.** The `ms-appinstaller:` link scheme has been disabled by default since December 2023. Users now download the `.appinstaller` file and double-click it [[9]](https://learn.microsoft.com/en-us/windows/msix/app-installer/app-installer-file-overview).
2. **Container rules.** The app cannot write to its install folder or to HKLM. In-process shell extensions and drivers are not allowed. Plug-ins installed as separate packages are isolated from the host [[11]](https://learn.microsoft.com/en-us/windows/msix/desktop/desktop-to-uwp-prepare). If Studio loads third-party plug-ins or writes config next to its exe, MSIX needs changes or the Package Support Framework [[11]](https://learn.microsoft.com/en-us/windows/msix/desktop/desktop-to-uwp-prepare).

Every MSIX must be signed [[8]](https://learn.microsoft.com/en-us/windows/msix/overview). Through the Store, Microsoft re-signs for free and users see no SmartScreen warning [[31]](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/code-signing-options)[[32]](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation). That makes the Store a good **second** channel once Studio has a Store listing.

**WiX Toolset** is at v7.0.1 (26 October 2026) [[13]](https://github.com/wixtoolset/wix/releases). The source is MS-RL [[16]](https://github.com/wixtoolset/wix/blob/main/LICENSE.TXT). Since v6, the project charges an **Open Source Maintenance Fee**. "If you use this project to generate revenue, the Maintenance Fee is required" [[15]](https://github.com/wixtoolset/wix). The FireGiant page sets the line at organisations with more than USD 10,000 a year in revenue, which must sponsor the `wixtoolset` GitHub organisation. In v7 you must accept the EULA with `AcceptEula` or `wix eula accept wix7` [[14]](https://docs.firegiant.com/wix/osmf/). Sponsor tiers are USD 10, 40 and 60 a month by company size (read 2026-10-30) [[17]](https://github.com/sponsors/wixtoolset). For Studio that is at most USD 720 a year, which is small. The real cost of WiX is authoring time: it has no updater, so you would pair it with NetSparkle or similar [[27]](https://github.com/NetSparkleUpdater/NetSparkle).

**Inno Setup** 7.1.1 came out on 28 October 2026 [[19]](https://jrsoftware.org/isdl.php). Since 6.5 it sells perpetual commercial licences with two years of updates, and renewal within two months costs 60% of the current price. The FAQ says buying is "not strictly required" but asks every commercial user to buy. It defines a commercial user as an organisation or freelancer with revenue above USD 5,000 a year [[18]](https://jrsoftware.org/isorder.php). The prices are rendered by the Paddle checkout and are not in the page HTML, so we record them as **behind checkout**. Inno can install with admin rights (default) or in non-admin mode (`PrivilegesRequired=lowest`) [[20]](https://jrsoftware.org/ishelp/topic_setup_privilegesrequired.htm). It has no updater or MSI output.

**Advanced Installer** is the commercial GUI option. Professional costs USD 399 per user per year or USD 599 perpetual. Enterprise costs USD 1,399 a year or USD 2,399 perpetual and adds the "Advanced Updater" and "Trial and Licensing". All prices are USD excluding VAT (read 2026-10-30) [[21]](https://www.advancedinstaller.com/purchase.html). Professional already includes MSIX, a basic updater and "Trusted Signing Native Integration" [[21]](https://www.advancedinstaller.com/purchase.html).

**NSIS** is zlib/libpng-licensed and free for commercial use. Its LZMA module is under CPL 1.0, with a linking exception [[22]](https://github.com/kichik/nsis/blob/master/COPYING) (read from a GitHub mirror because sourceforge.io blocked us; third party).

**Enterprise deployment.** Intune deploys any EXE or MSI as a "Win32 app" after wrapping it in `.intunewin`, but the installer must run silently [[30]](https://learn.microsoft.com/en-us/intune/intune-service/apps/apps-win32-app-management). So every option above works with Intune if it has a silent mode. An MSI also gives IT teams the familiar `msiexec /qn` and GPO route [[3]](https://docs.velopack.io/packaging/installer).

### Velopack and other updaters

**Velopack** combines installer, updater and delta packager in one tool [[1]](https://docs.velopack.io/)[[2]](https://github.com/velopack/velopack). The latest stable NuGet package is 1.2.161 (29 Sep 2026); 1.3.39 is a pre-release (17 Oct 2026) [[7]](https://api.nuget.org/v3/registration5-gz-semver2/velopack/index.json). What matters for Studio:

- **Install modes.** `Setup.exe` installs per user to `%LocalAppData%\{packId}` and launches the app. `vpk pack --msi` also builds an MSI with `--instLocation PerUser | PerMachine | Either`. Per-machine installs go to `Program Files`, use HKLM and need elevation. Admins can run `msiexec /i MyApp.msi /qn VELOPACK_INSTALLDIR="D:\Apps\MyApp"` [[3]](https://docs.velopack.io/packaging/installer).
- **WiX fee.** Velopack builds MSIs "using its own fork of WiX v7", and states that the OSMF "does not apply" to apps packaged with `vpk --msi` [[3]](https://docs.velopack.io/packaging/installer). That is Velopack's reading; if your lawyers disagree, sponsoring WiX costs at most USD 60 a month [[17]](https://github.com/sponsors/wixtoolset).
- **Deltas.** Zstandard binary patches, generated automatically when the previous release is in the output folder. No single file may exceed 2 GB. A user several versions behind downloads each delta in turn, or the full package when that is cheaper [[4]](https://docs.velopack.io/packaging/deltas). If Studio ships large geodata or font files, keep each under 2 GB.
- **Signing.** `--signParams` passes options to signtool, and `--signTemplate` runs any tool such as AzureSignTool. `--azureTrustedSignFile` signs with Artifact Signing; from Velopack 1.3 this works on any OS. App binaries, `Setup.exe` and the MSI are all signed. MSIs can only be built on Windows [[5]](https://docs.velopack.io/packaging/signing).
- **API.** `VelopackApp.Build().Run()` must be the first line of `Main()`, then you call `CheckForUpdatesAsync`, `DownloadUpdatesAsync` and `ApplyUpdatesAndRestart` [[6]](https://docs.velopack.io/integrating/overview).
- **Licence.** MIT [[2]](https://github.com/velopack/velopack).

**Measured: Velopack under Native AOT (Linux x64).** We used the sample from [`assets/C17/aot-samples/velo`](assets/C17/aot-samples/velo/Program.cs), published with `dotnet publish -c Release -r linux-x64` and `PublishAot=true` on .NET SDK 8.0.427 / runtime 8.0.33, with `TrimmerSingleWarn=false` so every warning is listed:

```csharp
using Velopack;
using Velopack.Sources;
VelopackApp.Build().Run();
var mgr = new UpdateManager(new SimpleWebSource("https://example.invalid/releases"));
Console.WriteLine($"installed={mgr.IsInstalled} version={mgr.CurrentVersion?.ToString() ?? "none"}");
if (args.Length > 0 && mgr.IsInstalled) {
    var info = await mgr.CheckForUpdatesAsync();
    if (info != null) { await mgr.DownloadUpdatesAsync(info); mgr.ApplyUpdatesAndRestart(info); }
}
```

**Squirrel.Windows** shows a "Contributors Needed" notice [[23]](https://github.com/Squirrel/Squirrel.Windows). Its fork **Clowd.Squirrel** was archived on 5 July 2024 and points to Velopack as its "new home" [[24]](https://github.com/clowd/Clowd.Squirrel). **ClickOnce** installs per user into a per-app cache, needs no admin rights, and downloads only changed parts [[26]](https://learn.microsoft.com/en-us/visualstudio/deployment/clickonce-security-and-deployment). On .NET 5 and later, `UpdateInterval` and background update mode are not supported, and the deployment API is only reachable through environment variables (from .NET 7) [[25]](https://learn.microsoft.com/en-us/visualstudio/deployment/clickonce-deployment-dotnet). **WinGet** is a distribution channel, not an installer. You submit a YAML manifest to `microsoft/winget-pkgs` [[28]](https://learn.microsoft.com/en-us/windows/package-manager/package/). It supports EXE (with silent flags), MSI, WiX, Inno, NSIS, MSIX, Burn, ZIP and portable installers, and users get `winget upgrade` [[29]](https://learn.microsoft.com/en-us/windows/package-manager/winget/). IT teams that script installs often look for a WinGet ID, so publishing one is cheap reach.

### Windows code signing in 2026

**Rules that changed.**

- *Validity.* CA/Browser Forum ballot **CSC-31** cut the maximum validity of code-signing certificates from 39 months to **460 days**, effective **1 March 2026**. It was adopted on 17 November 2025: certificate issuers voted 7 for, 0 against, 2 abstaining, and Microsoft voted for as the only certificate consumer. It is folded into the Code Signing Baseline Requirements v3.10.0 [[37]](https://cabforum.org/2025/11/17/ballot-csc-31-maximum-validity-reduction). CAs set their own margins: Certum allows 459 days from 27 February 2026 [[43]](https://shop.certum.eu/code-signing.html), and GlobalSign now sells only 1-year (366-day) certificates [[42]](https://shop.globalsign.com/en/code-signing). A "3-year" product now means re-issuing during the term [[43]](https://shop.certum.eu/code-signing.html). **Plan for at least yearly re-validation and key handling.**
- *Key storage.* Since June 2023, keys for OV certificates must be on an HSM or hardware token [[31]](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/code-signing-options). Velopack's docs say the same and warn that many token setups do not work in CI [[5]](https://docs.velopack.io/packaging/signing). We did not open the CA/B Forum ballot behind the 2023 rule (secondary sources only).

**SmartScreen now.** Microsoft's guidance is blunt: "EV certificates no longer bypass SmartScreen" [[32]](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation), and the bypass was removed in 2024 [[31]](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/code-signing-options). Reputation builds on the file hash and on the publisher certificate. A new signed app shows an "unrecognised app" prompt with the publisher name until reputation builds, which "can take several weeks and hundreds of clean installs". Signing every release with the same identity lets later releases inherit trust [[32]](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation). On Windows 11, Smart App Control blocks unsigned files that have no positive reputation [[32]](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation). In practice: **sign everything, keep one identity, never pay EV prices for SmartScreen**, and warn early adopters that they will see a prompt.

**Azure Artifact Signing** (formerly Trusted Signing) is Microsoft's managed service. It keeps certificates in FIPS 140-3 Level 3 HSMs and signs file digests, so your files never leave the build machine [[33]](https://learn.microsoft.com/en-us/azure/artifact-signing/overview). The Azure Retail Prices API lists **Basic at USD 9.99 a month and Premium at USD 99.99 a month**, with overage at USD 0.005 per signature (read 2026-10-30) [[36]](https://prices.azure.com/api/retail/prices?$filter=contains%28productName,%20%27Signing%27%29%20or%20contains%28meterName,%20%27Signing%27%29). The quotas are 5,000 and 100,000 signatures a month [[35]](https://azure.microsoft.com/en-us/pricing/details/artifact-signing/); the pricing page itself did not render prices for us. Eligibility is the blocker: **organisations in the USA, Canada, EU and UK; individuals in the USA and Canada only** [[31]](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/code-signing-options). It also needs a paid Azure subscription, issues no EV certificates, and allows no custom CN or O [[34]](https://learn.microsoft.com/en-us/azure/artifact-signing/faq). A UAE-registered Urbanto entity cannot use it. An EU or UK subsidiary could.

- **GlobalSign**: OV costs USD 529 (AED 1,945) a year with a USB token, or **USD 289 (AED 1,061)** if you bring your own HSM. GlobalSign was the only CA in this research to price in AED, and it asks you to order in your registered region's currency [[42]](https://shop.globalsign.com/en/code-signing). record Licence(string Id, string Customer, DateTime Expires, int Seats, string[] Modules, string Fingerprint);
```csharp
[JsonSerializable(typeof(Licence))] partial class LicJson : JsonSerializerContext {}

// licence file = base64(json) + "." + base64(signature); public key embedded in Studio
using var pub = ECDsa.Create(); pub.ImportFromPem(pubPem);
var parts = file.Split('.');
var payload = Convert.FromBase64String(parts[0]);
bool valid = pub.VerifyData(payload, Convert.FromBase64String(parts[1]), HashAlgorithmName.SHA256);
var lic = JsonSerializer.Deserialize(payload, LicJson.Default.Licence)!;
bool parkingEnabled = valid && lic.Expires > DateTime.UtcNow && lic.Modules.Contains("parking");
```

Output: `fileLen=317 valid=True parking=True expires=2027-10-30`. This is the same verify step you would run against a Keygen ECDSA-signed key. The only extra piece a service such as Keygen adds is the server: activations, seat counts, floating leases, revocation and the customer portal.

### Privacy-respecting crash reporting

**Sentry** is the default choice. Its .NET SDK is MIT-licensed [[65]](https://github.com/getsentry/sentry-dotnet). Team costs USD 26 a month billed annually (USD 29 monthly) and Business USD 80 a month annually (USD 89 monthly); both include 50k errors a month. The Developer plan is free with 5k errors and one user. The comparison table lists "Data Residency" on every plan, but the page does not name the regions [[61]](https://sentry.io/pricing/). The .NET SDK "purposefully does not send PII". `BeforeSend` lets you rewrite or drop events on the user's machine, while server-side scrubbing only stops storage, not sending [[62]](https://docs.sentry.io/platforms/dotnet/data-management/sensitive-data/). Self-hosted Sentry is FSL-licensed and becomes Apache 2.0 after two years. It needs at least 4 cores, 16 GB RAM plus 16 GB swap, and 20 GB of disk, and comes with no scaling support [[63]](https://develop.sentry.dev/self-hosted/). **GlitchTip** is a lighter, MIT-licensed backend that accepts Sentry SDKs [[70]](https://glitchtip.com/)[[71]](https://gitlab.com/glitchtip/glitchtip-backend). Hosted, it costs USD 15 a month for 100k events [[69]](https://glitchtip.com/pricing). It is the simplest way to keep crash data on a server in the UAE.

**Measured: Sentry .NET 6.12.1 under AOT (Linux x64).**

- **Build:** 0 trim/AOT warnings, binary 11.85 MB.
- **Native crash capture:** the package's `buildTransitive/Sentry.Native.targets` statically links `sentry-native` (with `libunwind` on Linux, `sentry-native.lib` plus dbghelp and winhttp on win-x64) when `PublishAot` is on for a .NET 8+ exe. Turning it off with `SentryNative=false` saved 0.43 MB [[84]](https://api.nuget.org/v3-flatcontainer/sentry/6.12.1/sentry.6.12.1.nupkg).
- **Symbols:** the package's `Sentry.targets` uploads AOT symbols with Sentry CLI after `_CopyAotSymbols` [[84]](https://api.nuget.org/v3-flatcontainer/sentry/6.12.1/sentry.6.12.1.nupkg). Without uploaded symbols, AOT stack traces can be "missing or unhelpful" [[64]](https://docs.sentry.io/platforms/dotnet/troubleshooting.md).
- **What is sent with defaults:** we pointed the DSN at a local Python receiver ([script](assets/C17/aot-samples/sentry-local-receiver.py)) and decoded the envelope ([raw](assets/C17/sentry-envelope-linux-aot.txt)).
  - `user` held only `{"id": "<random GUID>"}`, an installation ID stored on disk at `~/.local/share/Sentry/<hash>/.installation` on Linux.
  - `server_name` was null.
  - OS, runtime, time zone, culture and memory figures were included.
  - `debug_meta.images[].code_file` held the **full path of the executable**. On Windows, a per-user Velopack install path contains the Windows user name (`C:\Users\<name>\AppData\Local\...`). That is personal data.
- **Scrubbed version:** the consent-gated sample below reduced `code_file` to the bare file name. Verified output: `"code_file": "sentryconsent"` ([raw](assets/C17/sentry-envelope-linux-aot-scrubbed.txt)).

```csharp
if (!settings.CrashReportsConsented) return;          // opt-in, off by default
SentrySdk.Init(o =>
{
    o.Dsn = "https://<key>@<your-sentry-or-glitchtip-host>/<project>";
    o.SendDefaultPii = false;
    o.AutoSessionTracking = false;                    // no usage pings without separate consent
    o.SetBeforeSend(e =>
    {
        e.ServerName = null;
        e.User = new SentryUser { Id = e.User?.Id };  // keep only the random install id
        foreach (var img in e.DebugImages ?? new())
            if (img.CodeFile is { } p) img.CodeFile = Path.GetFileName(p);
        return e;
    });
});
```

Also scrub exception messages that may contain project file paths or client names before you rely on SaaS hosting.

**BugSplat** costs USD 24 a month for Starter (25k crashes) and USD 124 for Pro; self-hosted symbol servers come with Studio and Enterprise [[66]](https://www.bugsplat.com/pricing/). **Backtrace** Standard costs USD 900 per user per year for Mobile and PC, and its Professional plan offers "on-prem or your choice of cloud provider and region" [[67]](https://backtrace.io/pricing). **Raygun** charges USD 40 a month (annual) per 100k errors plus USD 0.001 per extra error [[68]](https://raygun.com/pricing). None of these three states a data region on its pricing page, except Backtrace Professional. All prices were read 2026-10-30.

**Windows Error Reporting LocalDumps** stores crash dumps only on the PC. Enabling it needs admin rights, because the key is `HKLM\SOFTWARE\Microsoft\Windows\Windows Error Reporting\LocalDumps`. Defaults are `%LOCALAPPDATA%\CrashDumps`, 10 dumps and minidump type. Per-exe subkeys override the defaults, and dumps are collected even when WER itself is disabled [[72]](https://learn.microsoft.com/en-us/windows/win32/wer/collecting-user-mode-dumps). A per-machine MSI could set a `LocalDumps\Studio.exe` subkey as the no-network fallback for air-gapped clients, who can then send dumps by hand.

**Consent and law.**

- **GDPR.** Processing needs a lawful basis under Article 6(1), such as consent (a) or legitimate interests (f), and legitimate interests fail where the person's rights override them [[73]](https://gdpr-info.eu/art-6-gdpr/) (text published by a third party).
- **UAE PDPL.** The UAE's federal Personal Data Protection Law (Federal Decree-Law No. 45 of 2021) has been in force since 2 January 2022. It prohibits processing without the owner's consent except in some cases, and sets rules for cross-border transfer. The DIFC has its own law (DIFC Law No. 5 of 2020) [[74]](https://u.ae/en/about-the-uae/digital-uae/data/data-protection-laws).
- **What we could not verify.** The full law text was blocked (HTTP 403) [[75]](https://uaelegislation.gov.ae/en/legislations/1972), so we could not confirm the exact consent exceptions, the free-zone scope or the transfer conditions.
- **Practical rule for both laws:** make crash reporting **opt-in**, say what is sent and where it is hosted, scrub paths and names on the client, and offer an in-region (UAE) self-hosted endpoint for clients who require it. Licence activation data (email, machine fingerprint) is also personal data, so cover it in the privacy notice.

### Pricing-model suggestion for Studio

The figures below are a **suggestion based on judgement**, anchored on the sourced benchmarks in Table 5. They are not market research.

- **Model: annual named-user subscription with paid modules.** This matches Giraffe Teams (per user per year) [[81]](https://www.giraffe.build/pricing) and Modelur's annual plan [[77]](https://www.modelur.com/pricing). It also maps directly onto Keygen or Cryptlex entitlements.
- **Studio Core: about USD 1,200 per user per year.** That sits between Modelur's EUR 888 per floating seat a year, for a plug-in that needs SketchUp or Rhino [[77]](https://www.modelur.com/pricing), and Giraffe Teams at USD 1,500 [[81]](https://www.giraffe.build/pricing). Monthly billing at about USD 150 per user. Modelur charges about twice its annual rate for monthly billing [[77]](https://www.modelur.com/pricing).
- **Parking module: about USD 600 per user per year.** Four seats would then cost USD 2,400, close to TestFit Parking Solver's USD 195 × 12 = USD 2,340 a year for a whole company [[76]](https://www.testfit.io/pricing). A small office therefore pays about what it would for TestFit's entry product, and larger firms pay more.
- **Floating seats at about 1.5 times the named-user price**, for firms that share seats. Rhino [[78]](https://www.rhino3d.com/sales/) and Modelur [[77]](https://www.modelur.com/pricing) both sell concurrent seats.
- **Free viewer** for clients and consultants, following Giraffe's free viewers [[81]](https://www.giraffe.build/pricing).
- **Government and closed-network tier**: offline-activated licence files with an expiry (for example 90 days, renewed by file). Allow a perpetual licence with paid upgrades only on request; perpetual licences are still normal in this tool category (Rhino 9 at USD 995) [[78]](https://www.rhino3d.com/sales/).
- **Publish AED prices** for the UAE alongside USD. None of the competitors does, according to the pages read.

## Risks and open questions

- **Windows not tested.** All AOT sizes and warnings are from `linux-x64`. Windows AOT output differs: different runtime pieces, Velopack's Windows code path, `sentry-native.lib` plus dbghelp and winhttp. Re-run the samples with `-r win-x64` on Windows before deciding. We also could not build an MSI, sign anything, or observe SmartScreen.
- **Velopack 1.3 is still a pre-release** (1.3.39, 17 Oct 2026) [[7]](https://api.nuget.org/v3/registration5-gz-semver2/velopack/index.json). Signing directly through `--azureTrustedSignFile` on any OS needs 1.3 [[5]](https://docs.velopack.io/packaging/signing). Its MSI relies on Velopack's reading that the WiX OSMF does not apply to its fork [[3]](https://docs.velopack.io/packaging/installer).
- **Prices not found:** Inno Setup licence prices (Paddle checkout only) [[18]](https://jrsoftware.org/isorder.php); Zentitle (HTTP 503) [[55]](https://zentitle.io/pricing); Wibu, Revenera and Thales (contact sales); Keygen EE; SSL.com eSigner subscription; DigiCert's OV versus EV split [[38]](https://www.digicert.com/signing/code-signing-certificates); Autodesk Forma (HTTP 403) [[82]](https://www.autodesk.com/products/forma/overview); Rhino 9 release date and Middle East price.
- **Keygen prices** come from the JSON API the pricing page loads [[45]](https://api.keygen.sh/v1/plans?limit=100). We read the amounts as US cents, because the page shows "$" and the add-ons match ("$995/mo"). Confirm in checkout.
- **GlobalSign prices** were read from data embedded in the page, not the rendered page [[42]](https://shop.globalsign.com/en/code-signing).
- **The HSM rule (June 2023)** is cited from Microsoft and Velopack, not the CA/B Forum ballot itself [[31]](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/code-signing-options)[[5]](https://docs.velopack.io/packaging/signing).
- **UAE PDPL:** the law text was not readable (HTTP 403) [[75]](https://uaelegislation.gov.ae/en/legislations/1972). Get local legal advice on crash data and licence telemetry, especially the transfer rules for SaaS hosted outside the UAE and the free zones (DIFC, ADGM).
- **LicenseSpring AOT failure** is a single test of 8.2.1 on Linux. LicenseSpring may offer AOT guidance or a different build; ask before ruling it out.
- **Search budget.** The shared web-search budget ran out mid-research. Later lookups used direct fetches of known vendor pages, so some vendor-specific claims (NSIS per-user behaviour, Zentitle offline method) remain open.
- **MSIX fit** depends on Studio's internals, which we do not know: plug-ins, writes beside the exe, shell integration. Check those against [[11]](https://learn.microsoft.com/en-us/windows/msix/desktop/desktop-to-uwp-prepare) before adding a Store channel.

## Choices made

- **Inferences relied on.** Studio is a Windows desktop C# (.NET) app considering Native AOT. It has modules that could be licensed separately (implied by the task line), for example 3D massing (from C2), parking layout (C12) and a live Excel link (C7). Its first market is the UAE, then Saudi Arabia and Qatar. None of this was confirmed from Studio's own files, which were unavailable.
- Treated Urbanto as a **UAE-registered company with no EU, UK, US or Canadian entity**. That is why Artifact Signing is marked ineligible; it becomes the cheapest option if such an entity exists.
- Measured on **.NET 8** (the SDK installed here), not .NET 9 or 10. Used the latest **stable** packages (Velopack 1.2.161, Sentry 6.12.1), not the 1.3 or 7.0 pre-releases.
- Used an **HttpClient + JSON baseline** to measure the size each library adds, assuming Studio already makes HTTPS calls. The hello-world deltas are also shown.
- Set `TrimmerSingleWarn=false` so every trim/AOT warning is listed separately. Counted distinct warning messages.
- Read **Keygen** prices from its public plans API, and **GlobalSign** prices from data embedded in the page, because both pages render prices by script. Did **not** call Paddle's API to reveal Inno Setup prices; recorded them as "behind checkout".
- Recorded TestFit's "$" as USD because the page names no currency.
- Picked **GlobalSign, SSL.com and Certum** as the main OV options because they show prices and cloud or own-HSM key options. DigiCert's page did not separate OV and EV prices.
- The **pricing suggestion** (USD 1,200 Core, USD 600 Parking, 1.5× for floating) is a judgement anchored on the Table 5 benchmarks, not market research. Exchange-rate conversion to AED was not done, because no rate source was fetched.
- Recommended **Keygen over Cryptlex** narrowly. It is cheaper at the 1,000-user tier (USD 99 against USD 100 a month), has a free self-hosted edition, and needs no native library. Cryptlex is equally valid and measured AOT-clean.
- Ruled out **MSIX as the primary channel**: its restrictions may clash with plug-ins or writes beside the exe, which we cannot check without Studio's code. It is kept as an optional Store channel.
